# 기존 셔틀 모델 비교 범위

v0.1.0 · 2026-09-11

기존 파일: 02. ChatGPT/4_4Way Shuttle/4way_shuttle_calculator_v2.html

신규 파일: 5_통합 물동량 계산 프로그램/셔틀_실행.html

## 실제 수행한 비교

1. 기존 파일에서 순수 FEM 계산 블록을 추출해 기존 selfTest() **66건을 실행**, 전부 통과했습니다.
2. 기존 travelTime과 신규 공통 운동 커널의 정지→정지 이동시간을 **32개 거리·속도·비대칭 가감속 조합**에서 비교했습니다. 차이는 1e-8초 미만입니다.
3. 별도 독립 수치로 신규 경로의 SC 41.098386677초, DC 45.098386677초, 리프트 SC 10.4초, 첫 입고 적치 29.749193338초를 검증했습니다.

재실행: node scripts/legacy-check.js

원본 SHA-256, 기존 자체검증 이름·기대값·실제값·주석, 32개 운동 비교값은 [legacy-results.json](./legacy-results.json)에 보존했습니다.

## 범위 차이

| 항목 | 기존 v2 | 신규 v0.1.0 |
|---|---|---|
| 수평 모델 | 기준식과 4-way 추가시간 | X/Z 각 경로·전환·정위치 단계 |
| DC 물량 | 기존 시스템 집계 방식 | min(입고, 출고)만 결합, 잔여 SC |
| 재고 | 해석식 중심 | 실제 TU와 저장 셀 예약·소유권 |
| 제어 | 해석적 산정 | 통로·교차로·인계부 시간 예약과 DES |
| 층별 배치 | 이전 모델의 가정 | 층고정 셔틀, 층별 수요 제약 |
| 리프트 | TU·차량·다중 적재 등 기존 모델 | 독립 TU 리프트 1~4대, 1개 화물 |
| 더블딥·이동배치 | 이전 모델에 존재 | 미지원 |

따라서 시스템 전체 물동량을 동일 값으로 맞추는 비교가 아닙니다. 기하학적 경로·주차 복귀·정차 제어·수요 배분 가정이 다릅니다.

## 표준 검증과의 구분

위 66건은 **기존 코드에 들어 있던 자체검증**입니다. 기존 코드에는 차량 리프트 예시의 tW=3초 가정, 일부 부록값 대신 식 기준값을 사용한다는 주석이 포함되어 있습니다.

이번 구현에서 FEM 원문 PDF를 독립 대조하지 않았습니다. 이 결과는 원문 적합성 검증이나 인증을 의미하지 않으며, 기존 파일의 더블딥·차량 리프트·다중 적재 기능을 신규 프로그램에서 지원한다는 의미도 아닙니다.

## 핵심 확인 사항

- 삼각형·사다리꼴 및 비대칭 가감속의 독립 정답, 정지·위치 연속성.
- 독립 경로 정답: 셔틀 SC 41.098386677초, DC 45.098386677초, 리프트 SC 10.4초, 최초 적치 29.749193338초.
- X/Z 순차 이동, 방향 전환, 실제 교차로·통로 예약, 본선 밖 주차 연결로.
- DC min(입고, 출고) 처리, 편측 수요, 층별 수요 편중, 무차량 층, 정수 필요 대수.
- 가용도·효율과 피크 계수의 적용 위치 및 중복 방지.
- 준비운전 통계, 최초 배차 대기와 미완료, 반복 신뢰구간.
- 시드 재현, 실행 시간 분할 독립성, 조합 간 동일 도착.
- TU 보존·저장 셀 중복 방지, 재고 부족·만재 대기, 새 입고 재고의 후속 출고.
- 유한 버퍼의 예약 포함 용량, 외부 반출 병목, 복수 리프트.
- 4대/층·복수 리프트 실행에서 0.2초 간격으로 연속 운동식을 평가한 차체 겹침 검사.
- 전체 예약 시간구간의 장비 간 중첩 검사.
- 화면 단위 환산, 입력 검증, 프로젝트 JSON, CSV, 완료 로그, MD.
- 층 선택·차체 클릭 선택·카메라·리프트 수직 추적·재고 인스턴스와 엔진 상태 일치.
- 큰 화물·층당 6대·리프트 4대의 주차 구역과 레이아웃 카메라 범위.
- 보고서 메타데이터·계산·관측 결과를 포함한 인쇄용 HTML 미리보기.
- Worker 12회 조합 실험, 취소, Worker 없는 분할 계산 2회 실험.
- WebGL 비활성 및 실행 중 컨텍스트 손실 시 2D 전환, 모바일 화면 폭.

분석은 입력된 층별·방향별 수요 비율을 유지합니다. 관측 합계는 실제 완료의 합계이므로 서로 비율이 달라질 수 있습니다. blocked의 합계 194는 입고 134 + 출고 60으로, 요구 출고 144를 달성하지 못합니다.

기본값의 업무량 기준 필요 대수는 총 셔틀 8대·리프트 2대입니다. 무경합 기준이므로 실제 대수 선정은 층별 관측 미달과 예약 대기를 확인해야 합니다.

## 적용 범위

검증 대상은 층고정 4-way 셔틀 + 1개 화물 적재 TU 리프트 모델입니다. 통로 독점과 전체 경로 사전 예약은 보수적인 제어 가정입니다. 측정값과 장비 정격·이재 방식의 현장 대조가 필요한 설계 검토 도구입니다.

브라우저에서 실제 출력 파일과 보고서 미리보기를 검증했습니다. 별도 PDF 파일의 페이지별 인쇄 렌더링 검증은 수행하지 않았습니다.

기존 자체검증의 재실행은 FEM 원문 적합성 인증이 아닙니다. 원문 독립 대조 및 기존 미지원 시스템 모드 이식은 수행하지 않았으며 [기존 모델 비교](./기존모델_비교.md)에 구분했습니다.

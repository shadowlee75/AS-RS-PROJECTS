# 개발계획서 대비 구현 범위

계획서 버전과 프로그램 버전은 다릅니다. 계획서는 v1.0이며, 구현 프로그램은 **v0.3 운영 검토판**입니다. 기능이 표시되더라도 전체 정식 검수·현장 검증을 마친 것으로 취급하지 않습니다.

| 기능 | 이번 구현 | 남은 정밀화 |
|---|---|---|
| F01 프로젝트 | 생성·예제·복제·JSON/Excel 저장·가져오기 미리보기·설정 해시·브라우저 마지막 적용 복구 | 프로젝트 목록·완전한 버전 이력 UI |
| F02 장비 | AGV/AMR 이름과 실제 기능 분리, 리프트/롤러, 공차/적재 v/a/b, 하중·외형·회전 | 지게차·조향·견인·혼합 기종 |
| F03 레이아웃 | 2D 드래그·노드·직선 경로·폭·방향·속도·정지점·도어·충전기 | CAD 배경·축척, 곡선·구역·기둥·벽·정밀 외곽 검사 |

## 정식 버전과 구분할 사항

- 별도의 연속 추종 모델을 구현하지 않았습니다. 이번 결과의 모델명은 `conservative-route-reservation@1`입니다.
- 매 작업 후 전용 주차 베이 복귀를 사용합니다. 해석 EG·최소 재배치와 DES 이동 정책이 같다고 가정하지 않습니다.
- 요청 코호트의 완료 P95와 미완료/기한초과를 함께 보여줍니다. 미완료를 버리고 납기율을 높이지 않습니다.
- 짧은 초기 완충 운전은 지속 처리능력으로 확정하지 않습니다. 차량별 2회 충전 방문과 말기 SOC는 간이 선별 조건입니다.
- 화면의 랙은 설명용 시각 모델입니다. 실제 도면 장애물 간섭과 안전 인증 검증은 포함하지 않습니다.
- 이 구현의 테스트 제목에 있는 T 번호는 계획서 주제와의 연결입니다. 일부 항목은 **이번에 지원하는 보수적 모델의 부분 검증**이며, 원본 계획서의 모든 검수 조건을 통과했다는 뜻이 아닙니다.

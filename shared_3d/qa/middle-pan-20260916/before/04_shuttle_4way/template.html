관측 처리량·대수 조합

95% CI는 반복 평균의 Student t 구간, 1회는 미산정입니다. 수요가 낮으면 최대 능력을 확인할 수 없습니다. 총량과 층별 입출고 미달을 함께 비교하세요.

MODEL & ASSUMPTIONS

계산 근거와 사용 순서

배치 → 수요 → 계산 → 3D → 조합 실험

층별 셔틀 수와 입출고 요구량을 입력하고 계산 및 설정 적용을 누릅니다. 경험 추정과 요구량을 비교한 뒤, 실제 재고·리프트 대기·교차로 예약·출고 정체를 시뮬레이션에서 확인합니다.

실제 두 수평축 경로

각 통로는 전면 크로스레일로 연결됩니다. X와 Z는 순차로 이동하고 방향이 바뀔 때 전환시간을 적용합니다. 교차로 사이와 통로 왕복 구간은 정지 상태에서 출발·도착하는 가감속 선도를 사용합니다. 대기 차량은 개별 주차칸에 있고 별도의 공용 연결로로 본선에 진입합니다.

단일·복합 사이클과 능력

DC 결합 작업 수/h = min(입고/h, 출고/h)
SC 작업 수/h = 입고/h + 출고/h − 2 × DC 작업 수/h
자원 업무량 s/h = SC 수 × T_SC + DC 수 × T_DC
부하율 = 업무량 / (3600 × 대수 × A × Ew)
독립 균형 셔틀 수 = 리프트 능력 / 셔틀 1대 능력

셔틀 DC는 같은 층끼리, 리프트 DC는 준비된 입출고 층 사이에서 결합합니다. 분석은 서로 다른 실제 저장 셀의 균일 분포를 가정해 베이·통로별 시간을 가중합합니다. 시뮬레이션은 실제 비어 있는 셀과 출고 가능한 재고를 선택하고, 배차 시 준비된 작업만 결합합니다.

층별 병목

분석 능력은 층별 입출고 비율을 유지하는 능력입니다. 총 셔틀 대수가 충분해도 수요가 몰린 층이 부족하면 전체 계획을 달성할 수 없습니다. 시뮬레이션 입고+출고 합계만으로 수요 충족을 판정하지 않습니다.

자원·버퍼 예약

작업의 출발부터 주차 복귀까지 경로를 미리 예약하고 다른 장비와 충돌하면 시작 시각을 늦춥니다. 교차로는 인접 이동 구간과 함께, 통로는 이동·이재 중 독점합니다. 이는 보수적인 구간 제어이며 고속 연속 주행을 가정한 최대 능력이 아닙니다. 고정 인계 버퍼는 작업 배정 전에 공간을 확보합니다.

통계와 재고

입고 완료는 랙 적치, 출고 완료는 지상 리프트 하차, 외부 출하는 지상 버퍼 반출입니다. 초기 재고와 도착 입고는 항상 저장·대기·운반·버퍼·외부 출하 중 한 위치에만 있습니다. 출고 요청 자체는 새 화물을 만들지 않습니다.

준비운전 상태는 측정구간에 이어집니다. P95 최초 배차 대기는 측정 중 배차된 요청 기준이며 미배차 최장 대기를 함께 읽어야 합니다. 장비 가동률은 실제 이동·이재·전환 시간 비율이며 예약 대기를 별도로 표시합니다.

모델 범위·저장

층고정 셔틀, 독립 샤프트 화물 리프트 1~4대, 화물 1개 적재, 양측 단일 깊이 랙을 지원합니다. 차량 층이동·다중 적재 리프트·더블딥·배터리·고장·SKU 제약은 포함하지 않습니다. 화물 유형별 예시는 벤더 보증값이 아니므로 실제 제원과 정격을 입력하세요.

프로젝트 JSON은 설정과 도착 이력을 저장합니다. 진행 상태는 저장하지 않으며, 완료 로그와 반복 실험 결과는 별도 내보내기를 사용합니다. PDF 보고서는 현재 적용 결과를 사용합니다. 입력을 재적용하기 전에 필요한 결과를 내보내세요.

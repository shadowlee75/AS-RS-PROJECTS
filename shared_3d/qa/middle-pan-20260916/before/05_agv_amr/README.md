# AGV·AMR Flow Studio

`PLAN-AGV-AMR-001` 개발계획서 기반의 **v0.3 운영 검토판**입니다. 사용자 실행 파일은 상위 폴더의 `AGV_AMR_실행.html`, 사용 안내는 `AGV_AMR_사용매뉴얼.md`입니다.

## 실행·빌드·검증

```powershell
node scripts/build.js
node tests/invariants.js
node scripts/serve.js
```

빌드는 외부 라이브러리·Worker·프로그램 모듈을 단일 HTML에 포함합니다. 개발 서버는 `http://127.0.0.1:8765`이며, 일반 사용자는 HTML을 직접 열면 됩니다. 사용자 입력과 계산 결과를 전송하는 외부 서버가 없습니다.

브라우저 QA에는 로컬 Playwright와 Edge가 필요합니다. 배포 HTML 실행에는 필요하지 않습니다.

```powershell
$env:AGV_PLAYWRIGHT_PATH = '설치된 playwright 모듈의 절대경로'
node scripts/browser-check.js
```

## 계산 계약

- 모든 내부 거리는 m, 시간은 s, 속도는 m/s, 에너지는 Wh입니다.
- 사용자 화면과 Excel 노드 좌표·경로 폭은 mm, 속도는 m/min입니다. Project 시트는 SI 설정을 명시적으로 보존합니다.
- 결정은 시뮬레이션 시간에서만 수행합니다. Three.js는 계산 결과를 변경하지 않습니다.
- 요청 이력 난수는 배차·차량 수와 독립적으로 생성합니다.
- 차량 상태 구간은 `[start,end)`이며 시작/끝 에너지·운동·화물 상태를 보존합니다. 재생은 이 로그를 이진 탐색해 직접 조회합니다. 체크포인트 재계산 없이 이전 시각의 상태를 조회하는 방식입니다.
- 처리량 완료창과 리드타임 요청 코호트는 다릅니다. 미완료·기한초과·최장 경과시간을 제외하고 충족 판정을 하지 않습니다.
- 해석의 기술/충전 가용도와 교통 시간배수는 DES에 다시 적용하지 않습니다.

## 교통 모델

출발 전 경로 전체의 충돌 공간과 목적지 단일 점유를 확보합니다. 활성 이동 경로와 정지 차량의 적재 포함 원형 외곽을 검사합니다. 시간상 겹친 경로가 기하학적으로 가까우면 후속 차량은 현재 노드에서 기다립니다. 동적 경로는 폐쇄·다른 차량 예약을 피하는 대안을 탐색합니다.

이 모델은 경로 전체 예약의 보수성이 있습니다. `링크 단일 점유`보다도 넓은 경로를 한 번에 예약하므로 정밀 관제의 연속 추종 처리량으로 해석하면 안 됩니다. 교착은 대기 그래프 순환의 장시간 무진전을 기록하며, 실제 차량을 순간 이동해 해소하지 않습니다.

지게차·견인·곡선/조향·연속 추종·보호필드·SLAM·실차 제어는 지원하지 않습니다. 상세 지원 현황은 [구현범위.md](구현범위.md)를 확인하세요.

## 의존성과 배포 무결성

새 외부 의존성 설치 없이 기존 `04_shuttle_4way/vendor`의 Three.js r128과 OrbitControls를 동일 해시로 사용했습니다. `vendor/manifest.json`의 파일 해시가 다르면 빌드가 중단됩니다. `qa/build-manifest.json`에는 원본 모듈·Worker·최종 HTML의 SHA-256이 기록됩니다.

XLSX 입력기는 기본 값 중심 템플릿용입니다. Excel 계산 엔진·스타일/수식/매크로 호환 편집기는 아닙니다. 수식·누락 단위·예상하지 않은 시트·CRC 오류를 거부하며, 가져오기 검증이 끝나기 전 기존 설정을 수정하지 않습니다.

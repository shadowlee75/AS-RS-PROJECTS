# LOOP RGV v0.2.1 검증 결과

검증일: 2026-09-15

## 수정 내용

- 설비스테이션 최대 30개에서 200개, 측정시간 최대 4시간에서 24시간으로 확대했습니다. 모델과 엑셀 검증이 같은 한도를 사용합니다.
- 측정시간 오류에 실제 입력값·단위·예시를 표시합니다. 8시간은 숫자 `8`, 30분은 `0.5`입니다.
- OD물동량·작업이력의 누락 스테이션 참조를 ID별로 묶어 표시하고, 수정할 시트·행과 방법을 안내합니다.
- 불러오기 검증 실패 시 이전 입력과 시뮬레이션 결과를 보존합니다.
- 많은 스테이션을 표시하는 2D 배치도에서 모든 지점 표시를 유지하고 겹치는 이름을 생략합니다. 마우스를 올리면 해당 ID·이름·위치를 볼 수 있습니다.
- 실행 HTML, 사용매뉴얼 PDF·HTML·Markdown을 갱신했습니다.

## 실행 검증

| 검증 | 결과 |
| --- | --- |
| 모델·엑셀·확장 입력 테스트 | 59개 통과 (기존 계산 39, 엑셀 14, 확장 입력 6) |
| 배포 HTML 검사 | 39개 검증 그룹 통과, 12개 인라인 모듈의 소스 SHA-256 일치 |
| 기존 엑셀 브라우저 검사 | 18개 통과 |
| 확장 입력 브라우저 검사 | 14개 통과, JavaScript 오류 및 외부 요청 없음 |
| 100개 스테이션·8시간 | 엑셀 불러오기, 50개 OD 유지, 100개 3D 지점 표시, 준비운전 포함 전체 시뮬레이션 완료 및 물동량 보존 확인 |
| 200개 스테이션·24시간 | 엑셀 불러오기·재저장, 조건 계산, 200개 2D 지점 및 3D 표시 확인 |
| 24시간 전체 계산 | 차량 1대·희소 작업이력 조건의 모델 테스트로 완료 및 물동량 보존 확인 |
| 잘못된 입력 | 문자열 시간과 누락 ID 3개의 오류를 묶어 표시하고 이전 입력·결과 보존 확인 |
| 매뉴얼 | PDF 16쪽 렌더링 및 전체 페이지 육안 확인, HTML 데스크톱·모바일 목차·이미지·확대·넘침 검사 통과 |

200개 스테이션·24시간 조건은 불러오기와 표시를 검증했습니다. 해당 조합의 전체 24시간 시뮬레이션을 수행했다는 의미는 아닙니다. 기존 계산 규모 및 작업 수 한도는 계속 적용됩니다.

## 검증 자료와 재현

- `browser-results.json`: 확장 입력 브라우저 검증 항목과 오류·외부 요청 목록
- `100stations-simulation.png`: 100개 스테이션의 8시간 계산 결과
- `grouped-errors.png`: 누락 ID 및 측정시간 오류 안내와 200개 스테이션 배치도
- 같은 폴더의 XLSX: 자동 생성한 정상·오류 재현 입력 및 재저장 결과
- `before/`: 수정 전 실행 파일과 관련 소스 백업

프로젝트 모듈 폴더에서 실행:

```powershell
node --test tests/core.test.js tests/excel.test.js tests/large-input.test.js
node scripts/shipcheck.js
# 설치된 Playwright 폴더를 LOOP_PLAYWRIGHT_PATH에 지정한 뒤 실행
node scripts/large-input-browser-check.js
```

## 사용자 원본 파일 상태

오류 화면에 사용된 사용자 원본 엑셀은 아직 확보하지 못했습니다. 누락된 P23 등의 실제 위치·상하차시간·버퍼 사양을 임의로 생성하지 않았습니다. 원본 파일에서 설비스테이션 ID와 OD물동량·작업이력의 참조 ID를 일치시켜야 합니다.

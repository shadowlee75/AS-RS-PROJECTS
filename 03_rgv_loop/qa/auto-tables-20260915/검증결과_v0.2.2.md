# LOOP RGV v0.2.2 검증 결과

검증일: 2026-09-15

## 요청 반영

사용자가 선택한 같은 번호 연결(P1→D1)을 기본으로 적용했습니다.

- 스테이션 ID 입력 완료·추가·삭제 시 OD와 빈 시간대 표를 갱신합니다. 새 OD는 0개/h이며 기존 유효 OD의 ID·물동량을 유지합니다.
- 스테이션 이름과 사양을 임의 생성하지 않습니다. 같은 번호의 P와 D가 모두 등록되어야 자동 연결합니다.
- 화면에서 기존 스테이션 ID 변경 시 OD·작업이력 참조를 함께 변경합니다. 중복 ID와 미완성 쌍으로 연결을 추측하지 않습니다.
- 스테이션 삭제 시 해당 OD를 제외 목록으로 보관합니다. 작업이력에서 사용 중인 스테이션 삭제는 이력을 먼저 정리하도록 안내합니다.
- 자동 시간대는 준비운전과 측정 1시간 간격으로 구성합니다. 운전시간 변경 시 기존 배율을 유지하고 추가 구간은 100%로 채웁니다. 수동 모드와 직접 편집을 지원합니다.
- 연속된 같은 배율 구간은 도착 생성 시 합쳐 처리합니다. 자동 100% 표를 추가해도 동일 시드의 작업 도착 시각이 바뀌지 않습니다.
- 엑셀 누락 스테이션 OD는 원본 행·ID·물동량을 확인한 뒤 정리·적용할 수 있습니다. 제외 OD CSV 보관과 취소를 제공합니다. 잘못된 숫자·단위·겹친 시간대·작업이력 오류는 계속 검증합니다.
- 자동 생성 모드는 엑셀 및 JSON에 저장하며 이전 버전 파일도 읽습니다. 자동 생성은 프로그램에서 수행합니다.

## 재현 자료

- `browser-results.json`: 자동 표 화면 검사 목록
- `200stations-blank-tables.xlsx`: 스테이션만 채운 입력표 재현용
- `56-missing-ids.xlsx`: 오류 화면과 같은 누락 ID 집합을 만든 재현용
- `repaired-conditions.xlsx`: 재현용 조건을 정리한 후 프로그램에서 저장한 결과
- `excel-excluded-OD.csv`, `station-delete-removed.csv`: 제외 행 보존 확인
- `auto-generated-tables.png`, `auto-table-controls.png`, `auto-time-table.png`: 자동 입력표
- `repair-preview.png`, `repaired-simulation.png`: 정리 화면과 8시간 계산
- `manual-pages/`: 개정 매뉴얼 렌더링
- `before/`: 이전 소스·실행 파일 백업

위 엑셀은 자동 생성한 검증용 자료입니다. 사용자 오류 화면의 원본 엑셀 파일은 제공받지 않았으며, 실제 설비 위치·사양을 대신 작성한 파일이 아닙니다.

## 검증 명령

```powershell
node --test tests/core.test.js tests/excel.test.js tests/large-input.test.js tests/tables.test.js
node scripts/build.js
node scripts/shipcheck.js
# 설치된 Playwright 경로를 LOOP_PLAYWRIGHT_PATH로 지정
node scripts/auto-tables-browser-check.js
node scripts/excel-browser-check.js
```

브라우저 검사는 로컬 Edge로 실행했습니다. 실행 프로그램은 외부 자원을 요청하지 않는 단일 HTML입니다.

# LOOP RGV v0.2.0 엑셀 입력조건 교환

2026-09-15

## 구현

- 기존 오프라인 실행 파일에 엑셀 저장·엑셀 불러오기 추가.
- 전체 기본조건 및 설비스테이션, OD물동량, 시간대비율, 제한속도, 작업이력, 실험조건 저장. 안내를 포함해 8개 시트.
- 숫자·문자형 셀, 선택 목록, 비율·정수 서식, 편집 영역 강조, 첫 행 고정과 필터.
- 고정 엑셀 단위 m·m/min·m/s²·s, 총 상하차시간. 화면의 거리·속도 단위와 상세 이재 표시로 변환.
- 현재 편집 중인 값 저장, 전체 검증 후 일괄 불러오기. 실패 시 기존 입력·완료 결과 유지.
- CRC·압축 해제 크기·셀 수·스키마·필수 필드·범위·스테이션 참조·시간대 겹침 검사.
- 실제 Excel 재저장 형식인 deflate 압축, sharedStrings, 셀의 숫자 유형과 백분율 처리.
- 차량 수를 줄여 불러올 때 이전 선택 차량 번호가 범위를 초과하던 표시 오류 수정.

## 확인 결과

| 검사 | 결과 |
|---|---|
| 기존 계산 엔진 39개 + 신규 엑셀 14개 | 53개 통과 |
| 배포 HTML 모듈·소스 SHA-256·동일 계산 검사 | 12개 내장 모듈, 39개 검사 통과 |
| 기존 Edge UI·3D·Worker·대체 표시 | 40개 통과 |
| 엑셀 UI 저장·불러오기·실패 보존·반응형 | 18개 통과 |
| 실제 Microsoft Excel 수정·저장 후 재입력 | 8개 브라우저 검사 통과 |
| Excel 8개 시트의 인쇄 렌더 검토 | 형식·숫자·문자·비율 확인 |
| 매뉴얼 개정 1.2 | 16쪽 PDF, HTML 14개 장·이미지·목차·모바일 검증 |

실제 Excel 검사에서는 차량 수, 화면 단위, 화물 단위, 피크·목표 비율, 스테이션 좌표와 총 이재·버퍼·반출, OD 수요, 2개 시간대, 제한속도, 작업이력, 실험 대수·반복을 변경했습니다. 재입력 후 계산 종료와 화물 보존 정상까지 확인했습니다.

20,000건 작업이력 왕복과 파일 크기 한도, 빈 숫자를 0으로 오인하지 않는지, 수식의 저장된 결과를 조용히 적용하지 않는지도 확인했습니다. 모든 브라우저 검사에서 외부 HTTP 요청과 JavaScript 오류가 없었습니다.

기존 실행 파일·변경 전 소스·매뉴얼은 before/에 보관했습니다. 사용자 배포용 입력조건 파일은 프로그램의 실제 다운로드 결과를 outputs/loop-rgv-excel-20260915/에 복사한 것입니다.

## 사용 범위

프로그램이 내보낸 .xlsx 양식을 편집하여 불러옵니다. 임의 양식, .xls, .xlsm, 암호화 파일은 지원하지 않습니다. 수식은 확정 값으로 변환해야 합니다. 엑셀은 입력 및 실험 조건을 저장하며 실행 중 상태·완료 로그는 별도 결과 파일로 보관합니다.

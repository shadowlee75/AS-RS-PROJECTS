# LOOP RGV 매뉴얼 검증

2026-09-15 · 프로그램 v0.1.0 · 문서 개정 1.1

- 현재 실행 파일에서 5개 예제를 실행하고 결과를 확인함: 기본 144, 단일 차량 30, 출고 버퍼 정체 60, 고정 블록 146, 작업이력 6 PLT/h.
- 6·8·10대, 각 3회 실험 화면과 실제 배포된 Blender 장비 표시 화면을 캡처함.
- PDF 14쪽, 14개 장, 본문 스크린샷 9개. 한글 텍스트 추출과 모든 장의 존재를 확인함.
- Poppler 120 dpi 렌더링으로 전체 페이지를 확인하고 3D 조작 표와 예제 결과 표를 추가 확대 확인함.
- HTML 데스크톱 1440 px / 모바일 390 px에서 문서 가로 넘침 없음. 목차 링크 14개, 이미지 로딩, 이미지 확대와 닫기를 확인함. 브라우저 스크립트 오류 없음.
- 예제 전환 시 이전 선택 차량 번호가 새 차량 수를 초과하는 경우의 회피 방법을 문제 해결 표에 포함함.
- 프로그램 계산 코드와 실행 HTML은 변경하지 않음.

세부 기록: source-checks.json, manual-build.json, manual-html-qa.json, manual-pdf-qa.json.

문서 재생성: `scripts/build-manual.py`를 실행한다. Python에 reportlab, Pillow, pypdf가 필요하며 Windows의 맑은 고딕 글꼴을 사용한다. 배포 파일과 캡처를 갱신한 경우 본문 수치와 화면도 다시 확인한다.

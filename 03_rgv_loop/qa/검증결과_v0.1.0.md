- 기하학적 대수 한도·블록 제약·입력 오류·동일 위치 무시간 작업 거절

- 대수·배차 정책에 독립인 도착, 시간대 공백, 이력에 피크 중복 미적용
- 준비운전 상태 이월과 상태시간 보존, 배치·부분 배치·즉시 반출

- 도움말, JSON 다운로드·복원, 잘못된 입력 시 결과 사용 차단
- WebGL 8대 표시, 모델과 3D 차체 좌표·방향 일치
- 1배속·한 단계·시각 탐색·과거 탐색·종료 계산·화물 보존
- 정면·평면·입체·선택 확대·추적·이름 숨김·3D 차체 클릭·드래그 회전
- 완료 CSV, 3개 운동 그래프, 문서 정보와 현재 결과를 포함한 PDF 미리보기
- 1~4대×3반복 공통 시드 실험, JSON 결과, 실험 취소
- 16대 출고 정체, 역방향 블록의 실제 물리 위치에 맞는 색상 표시

기본 경험 추정 177.12023 /h와 무간섭 참고 226.71389 /h는 분석값이며 시뮬레이션 관측 완료 144 /h와 구분됩니다.

## 검증 중 수정한 사항

1. 곡선·블록 제동 경계의 수치 정밀도 처리: 감속 상한과 물리 제약을 유지한 상태에서 미세 반올림을 처리.
2. 이동 중 배차: 일반 정지거리와 저속 접근 구간에 필요한 감속거리 모두 확보 후 도달할 순환 결정.
3. 같은 시각 정산: 0초 이재 전환·즉시 반출을 결과 스냅샷 전에 처리.
4. 역방향 3D 블록: 운행 좌표를 물리 위치의 블록 인덱스에 변환.
5. 3D 클릭: 투명한 라벨 영역이 다른 차체 선택을 가로채지 않도록 실제 차체 메시만 선택.
6. 초기 정지 상태: 진전 없음 5초 기준을 추가해 배차 직후 교착 오인 방지.

## 검증 경계

고정 시간격자 기반 교통·이벤트 결합 모델입니다. 각 이벤트 전환의 격자 지연은 누적될 수 있습니다. 0.1초와 0.05초 비교는 단일 차량 검산 조건을 대상으로 했으며 모든 설계의 오차율을 보장하지 않습니다.

현장 데이터에 대한 η 교정, 실제 PLC·기계 안전, 곡선에서의 측방·회전 여유, 배터리·고장·추월·분기·대피선은 검증 범위에 포함되지 않습니다. 기존 Python 35개 시험은 소스가 없어 실행하지 않았습니다. 이번 자동 검증과 현장 검증을 구분합니다.

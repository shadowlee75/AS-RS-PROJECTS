# 컨베이어 v1.0 검증 결과

검증일: **2026-09-15**. 신규 컨베이어 모델의 자동 검증 결과입니다. 현장 설비 성능 보증이나 기존 cvcore/Excel 골든 데이터 호환 인증을 의미하지 않습니다.

## 요약

- 계산·통계·입출력·계약 자동 시험 **23개 통과**.
- Edge 오프라인 화면 시험 **14개 통과**.
- 7개 기본 배치 모두 입력 유효성·화물 보존 검증 통과.
- 추가 20개 혼합 배치·속도·ZPA·정지·시드 조합의 용량·화물 보존 검증 통과.
- 브라우저 미처리 예외 0건, 외부 HTTP 요청 0건.
- 3D 화면과 편집·결과·모바일·WebGL 미지원 화면을 스크린샷으로 확인.

## 3. 브라우저 검증

환경: Windows, 설치된 Microsoft Edge, Playwright 1.56.1, `file://` 단독 HTML. 브라우저 테스트는 독립 임시 프로필을 사용합니다.

1. 직접 실행, Worker 계산, 4개 KPI, 외부 요청 없음.
2. WebGL 3D canvas 실제 렌더링.
3. 재생·정지·초기화·시점 변경 중 최종 KPI 불변.
4. 7개 템플릿 계산과 화물 보존 표시.
5. 속도 m/min → m/s 변환, 수정 후 이전 결과 경고, 내보내기 차단, 재계산.
6. 화물 크기 초과 오류 표시 및 수정 후 정상 계산.
7. 프로젝트 JSON 저장·왕복 불러오기·외부 형식 거절.
8. CSV 결과·인쇄 보고서·연동 데이터 다운로드.
9. 시나리오 저장과 5가지 민감도 계산.
10. CSV 작업 이력 입력, 수요 모드 전환, 2개 화물 완료.
11. 다른 탭에서 계산한 뒤 3D로 복귀해 화면이 비어 있지 않음.
12. 390 px 모바일 화면의 가로 넘침 없음.
13. 미처리 브라우저 예외 없음.
14. WebGL 차단 시 2D 폴백과 운전 재생.

다른 탭에서 계산할 때 시점이 비정상화되는 문제와 입력값 변경 중 표를 재생성하면서 발생하는 오류를 검증 중 발견하여 수정했습니다.

## 4. 실행 성능 표본

Node.js v24.18.1에서 십자 배치 1시간·요청 20,000개를 약 **41 ms**에 계산했습니다. 사건 수 26,401개, 화물 보존 일치. 한 PC의 1회 계산 표본이며 브라우저 렌더링·다운로드 시간은 포함하지 않습니다. 대량 요청 대부분이 미투입 대기열에 남는 과부하 사례이므로 고복잡도 장시간 운전 성능의 상한을 뜻하지 않습니다.

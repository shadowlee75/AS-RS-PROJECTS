처음 사용하는 순서

  1. 기본 입력

    랙 크기, 칸 수, 속도, 요구량을 입력합니다. 속도는 m/min, 길이는 m입니다.

  2. 파라미터 확인

    운전효율 85%, 적재 사양 적용률 100%, 제어 지연 0.5초 등의 예시값을 확인합니다.

  3. 물동량 계산하기

    효율을 반영한 보정 처리량을 먼저 보세요. 목표 설계 부하율은 필요 대수를 판단하는 별도 기준입니다.

  4. 설정 저장

    프로젝트 저장은 전체 입력, 파라미터 설정 저장은 상세 조건만 보관합니다. 저장한 파일은 다음 검토에 다시 사용할 수 있습니다.

간편판은 평균 사이클과 물동량을 계산합니다. 재고·대기·3D 시뮬레이션이나 STC별 복합 배치는 기존 상세 프로그램을 사용하세요.

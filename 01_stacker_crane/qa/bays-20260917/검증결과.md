# Bay 수 상한 확대 — v0.3.2

106 Bay 입력 시 기존 최대값 80에 걸려 오류가 표시되었습니다. 입력·모델 검증 상한을 200으로 확대하고 도움말과 HTML/Markdown 매뉴얼을 갱신했습니다. 3D 번지 번호는 텍스처 폭에 맞춰 글꼴 크기를 조정합니다. 전체 셀 상한 120,000개는 유지합니다.

- `npm test`: 기존 83개 테스트 통과.
- `npm run build`: 실행 HTML 갱신.
- `npm run shipcheck`: 배포 모듈 45개 검증 그룹, 12개 스크립트 구문 정상.
- `node scripts/browser-bays-check.js`: 계산·브라우저 검증 17개 통과. 외부 요청과 JavaScript 오류 없음.
- 106 Bay × 14단 × 2면 × 1대: 싱글딥 2,968셀 / 더블딥 5,936셀.
- 전체 셀 평균 및 FEM 계산, 시뮬레이션의 재고·작업 보존, 마지막 106번지/14단/D2 선택, 운동 그래프, 프로젝트 저장/불러오기 확인.
- 최대 200 Bay의 입력과 3D 번호 표시, 201 및 소수 번지수 거부, 전체 셀 한도 검증 확인.

검증 기록과 화면은 같은 폴더의 `results.json`, PNG, `106-bay-project.json`에 저장했습니다. 변경 전 파일은 `backups/20260917_bay_limit`에 보관했습니다.

# STC Studio v0.2.4 검증 결과

검증일: 2026-09-10. 대상: 상위 폴더 `스태커크레인_실행.html`.

## 적용 동작

사용자 지정 상차는 **포크 OUT → 캐리지 UP 110 mm → 포크 IN**, 하차는 **포크 OUT → 캐리지 DOWN 110 mm → 포크 IN**입니다. 완전 신장한 포크가 정지한 상태에서 승하강하고, 입력한 안착 대기 후 포크를 인입합니다. IN 상차, 랙 하차, 랙 상차, OUT 하차 모두 같은 모델을 사용합니다.

입력 Y와 P1·P2는 화물이 놓인 중심입니다. 상차 후 적재 이동은 이재 승하강량만큼 높은 Y에서 진행하며, 하차 후에는 원래 중심으로 돌아옵니다. 포크 이재 시간에는 캐리지 운동시간이 포함됩니다. 추가 안착 대기는 별도이며 재고와 작업 완료 집계 시점은 포크 IN 완료입니다.

### 계산 검산

- 기본 vy=1 m/s, ay=dy=0.5 m/s²에서 0.11 m 정지-정지 운동은 삼각형 속도선도입니다. 독립 식 `t=2√(0.11/0.5)`로 **0.938083152초/이재**, 도달속도는 **14.07124728 m/min**입니다.
- 동일 사양의 승하강량 0 mm 조건과 비교하면 SC 입고/출고 각각 **1.876166304초**, DC **3.752332608초**가 추가됩니다. 적재 이동 양 끝의 높이 오프셋은 서로 상쇄되므로 이동거리에는 변화가 없습니다.
- 적재 비율 0.63, 비대칭 승강 가감속, 양·음 포크 방향, Z=0 포트, 음수·랙 밖 포트, 1단 Y=0을 검사했습니다. OUT 중 Y 정지, UP/DOWN 중 포크 정지, IN 중 Y 정지와 모든 동작 경계의 위치 연속성을 확인했습니다.
- 전체 셀 SC/DC 전수 경로와 분석 평균, FEM CASE 1~6 독립 구간 합, 이벤트·프레임·일괄 완료 결과 및 30개 조건의 재고·작업 보존 검사를 통과했습니다.
- 기존 모델 비교 16건은 명시적으로 승하강량 0 mm를 설정한 비교입니다. 기본 110 mm 조건은 위의 독립 운동식과 시간 증가량으로 검증했습니다.

## 사용 및 적용 조건

왼쪽 **주행·승강·포크 → 캐리지 이재 승하강량**의 기본값은 110 mm입니다. 승하강 시간은 현재 승강 Y 속도·가감속과 적재 비율을 사용하며, 별도 이재 저속 사양은 모델링하지 않습니다.

이전 프로젝트에 `transferLift`가 없으면 0.11 m가 적용됩니다. 기존 ‘승하강·안착’ 값에 승하강 시간이 포함되었다면 **이재 후 안착 대기**에 안착 대기만 남겨 입력해야 합니다. 이전 방식의 비교에는 0 mm를 사용할 수 있습니다.

110 mm는 사용자 지정 장비 사양이며 FEM 규정의 고정값을 뜻하지 않습니다. 검증은 소프트웨어 계산·재생에 대한 것으로 장비 실측 검증은 포함하지 않습니다.

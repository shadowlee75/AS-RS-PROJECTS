# STC Studio v0.2.5 검증 결과

검증일: 2026-09-10. 대상: 상위 폴더 `스태커크레인_실행.html`.

## 변경 내용

- 상단 **PDF 보고서** 버튼과 문서번호·제출처·작성자·검토자 입력창 추가.
- 선택 경로 배치도/가감속 그래프 및 현재 시뮬레이션 결과의 포함 여부 선택.
- 별도 미리보기 창에 A4 인쇄용 보고서를 생성하고 **PDF 저장 / 인쇄** 버튼으로 브라우저 인쇄 실행.
- 요약, 입력 사양, 운영 조건, STC별 실제 포트와 SC/DC, FEM 적용/참조 좌표, 그래프, 시뮬레이션, 민감도 및 적용 조건 포함.
- 적용하지 않은 입력 변경은 내보내기 차단. 시뮬레이션 미실행·준비운전·부분 결과·완료·제외를 구분.
- 기존 Markdown 다운로드 유지. 계산식과 운동 커널은 변경하지 않음.

연결된 Browser 목록이 비어 있어 독립 Playwright/Edge 138로 확인했습니다. PDF 인쇄 버튼의 실제 `window.print()` 호출과 인쇄용 CSS를 검사하고, 같은 보고서 창을 Chromium PDF 출력으로 저장했습니다. OS의 파일 저장 대화상자 자동 조작은 하지 않았습니다.

Poppler 26.07.0을 임시 QA 폴더에 설치해 PDF 페이지를 PNG로 렌더링하고 텍스트·용지 크기·글꼴 포함 상태를 확인했습니다. 이 도구와 Playwright는 배포 파일의 실행 의존성이 아닙니다.

## 주요 검증

1. 버튼 표시, 문서 옵션, 미적용 설정 차단, 보고서 생성, 인쇄 기능 연결.
2. PDF 내 이론 총 능력, SC/DC 수치가 현재 계산 모델과 일치함.
3. 문서번호 등의 HTML 특수문자가 그대로 텍스트로 표시되고 실행되지 않음.
4. 110 mm UP/DOWN 설명, 포트 음수/랙 외부 좌표, 실제 화물 중심과 FEM 참조 좌표 유지.
5. 기본 미실행 및 보정 미입력은 미산정·판정 보류. 진행 중에는 부분 결과, 완료된 실행에는 완료 표시.
6. 3축 6개 가감속 그래프 출력 및 포함 선택 해제.
7. STC 12대의 포트·계산 결과·FEM 대표점이 누락되지 않음. 긴 프로젝트명과 문서 정보를 보존하며 페이지 분할.
8. 모바일 문서 옵션이 화면 밖으로 넘치지 않음.
9. 네 PDF의 전체 36쪽 렌더링. 주요 표지, 동작 사양, 운영 조건, 다중 STC 표, FEM 좌표, 그래프, 시뮬레이션 및 민감도 페이지를 직접 확인. 긴 입력에서 한두 행이 별도 장에 남는 문제, 그래프 시간 축 단위의 겹침을 수정함.
10. PDF 바닥글에 문서 이름과 현재 페이지/전체 페이지를 표시. 보고서 생성 버튼 및 안내는 PDF 본문에 인쇄되지 않음.

## 증빙

`qa/v025-pdf/`:

- `v025-pdf-results.json`: 신규 브라우저 검사 결과
- `v025-default.pdf`, `v025-complete-fem.pdf`, `v025-partial.pdf`, `v025-long.pdf`: 생성 PDF
- 같은 이름의 HTML 및 TXT: 미리보기 원본과 PDF 텍스트 추출
- `final-*.png`: 최종 PDF 페이지 렌더링
- `qa/v025-base-results.json`: 기본 기능 회귀 검사

PDF 검증용 수치·문서 정보는 소프트웨어 확인을 위한 예시이며 제출 대상 설비의 확정 사양을 뜻하지 않습니다.

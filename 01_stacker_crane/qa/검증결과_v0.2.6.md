# STC Studio v0.2.6 검증 결과

검증일: 2026-09-10. 대상: 상위 폴더 `스태커크레인_실행.html`.

## 변경 내용

- 기본 구성 기준 147개의 ? 버튼: 모든 설정 입력, 6개 접기 메뉴, 5개 탭, 상단/시뮬레이션/운동/실험 조작, 결과 제목과 PDF 옵션.
- 한국어 항목별 의미·단위·자동값·입력 예시·계산 반영 방식 제공. 외부 포트와 화물 중심, 110 mm 이재 등 기존 사양에 맞춘 설명.
- 마우스 올리기와 설명 안으로 이동, 클릭/터치 고정, 다른 항목으로 전환, 재클릭·닫기·바깥 클릭·Esc 지원.
- 키보드 Tab/Enter/Space, 닫기 후 포커스 복귀, 버튼 이름과 펼침 상태 제공.
- 스크롤 영역 밖에서도 읽을 수 있는 공용 설명 창. 화면 크기에 맞추어 위치/크기를 조정하고 PDF 설정 창에서도 조작 가능.
- STC별 포트 표 갱신 시 열별 도움말 재연결. 입력값과 표의 행/열 구조 유지.
- 계산식과 운동 커널은 기존 그대로. 도움말은 JSON·계산서·PDF에 포함하지 않으며 화면 인쇄에서도 숨김.

연결된 Browser 목록이 비어 있어 임시 QA 폴더의 Playwright와 Edge 138.0.3351.95로 오프라인 HTML을 확인했습니다. 모바일은 터치 지원 브라우저 에뮬레이션으로 검증했습니다. 이 도구는 배포 실행 의존성이 아닙니다.

도움말 클릭이 접기 메뉴·탭·시뮬레이션 재생을 실행하지 않는지, 값 변경·재계산을 일으키지 않는지 확인했습니다. 입력 미적용 상태에서도 도움말을 열 수 있습니다. PDF 창에서 Esc는 도움말만 닫고 설정 창은 유지합니다. 화면 크기 변경 중 발생했던 이벤트 대상 오류를 수정한 뒤 최종 브라우저 검사를 다시 통과했습니다.

데스크톱 개요, STC별 포트 표, PDF 설정 창, 모바일 터치 화면을 PNG로 저장하고 직접 확인했습니다. 텍스트 겹침과 화면 밖으로 잘림 없이 읽을 수 있습니다. 최종 도움말 검사에는 PDF 미리보기 생성까지 포함하며, PDF 전체 페이지 재검증 범위는 v0.2.5 기록을 참조하세요.

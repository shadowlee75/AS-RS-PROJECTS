# STC Studio v0.2.3 검증 결과

검증일: 2026-09-10. 대상: 상위 폴더 `스태커크레인_실행.html`.

## 변경 내용

- 기본 및 STC별 IN/OUT X: −500~500 m, Y: −100~100 m. 랙 바깥과 음수 좌표 허용. 포크 Z의 스트로크 제한은 유지.
- 랙 길이·번지수·단별 높이를 포트 위치와 분리. 실제 외부 포트까지의 주행·승강·포크 경로와 OUT→IN 복귀를 계산.
- 2D 범위와 3D 레일·승강 범위·카메라에 모든 외부 포트 포함.
- 화물을 셀의 중앙에 배치. 시각화 셀 경계는 중심 높이 ± 단간격/2.
- 기본 P1·P2는 CASE 참조점에서 선택한 실제 화물 중심. 셀 주소·XYZ를 계산·2D·3D·운동 그래프·계산서에 공통 적용.
- 이론 좌표 비교 모드 유지. 실제 포트가 CASE 참조 배치와 다를 때는 설계 확장임을 표시하고, 참조 포트·실제 포트·이론 좌표·적용 좌표를 구분해 출력.

## 주요 검산

길이 33.9 m / 6 Bay인 랙은 외부 포트 X=−3 m 또는 X=38 m를 입력해도 화물 중심 X가 **2.825, 8.475, 14.125, 19.775, 25.425, 31.075 m**로 유지됩니다. 2대 × 6 Bay × 6단 × 2면의 **144개 3D 셀**과 **4개 P1/P2 표시**의 중심 좌표를 대조했습니다. 2D P1/P2 원의 중심도 해당 화물 사각형의 중심과 일치합니다.

대표점 선택은 별도의 알려진 값으로 검산했습니다. L=60, H=12, 6 Bay, 4단, 1단=0.5, 단간격=3, CASE 1에서 이론 P1=(12,8)은 실제 중심 **(15,6.5)**, 이론 P2=(40,2.4)는 실제 중심 **(35,3.5)**을 사용합니다. 등거리의 선택은 작은 셀 ID로 고정합니다. 이 셀을 방문하는 완전 SC/DC 운동 경로의 시간이 분석 결과와 일치합니다.

외부 포트 X=−5/18, Y=−1/10인 소형 랙에서 모든 셀 SC 및 서로 다른 셀 쌍 DC를 전수 열거해 분석 평균과 비교했습니다. 음수·외부 포트의 2대 시뮬레이션은 프레임 재생과 일괄 완료의 로그·통계가 같고 재고 및 작업 보존을 만족합니다.

외부 포트가 CASE 조건과 다른 상태에서는 실제 중심 모드로 계산하고 설계 확장을 표시합니다. 이론 좌표 비교로 변경하면 원래 CASE 조건 오류를 표시합니다. CASE 1~6을 바꿔도 실제 외부 포트를 덮어쓰지 않습니다. JSON 저장·복원과 계산서의 적용/참조 좌표를 확인했습니다.

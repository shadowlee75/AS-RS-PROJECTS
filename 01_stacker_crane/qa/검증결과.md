## UI 검사

1. 외부 연결 없이 HTML 파일 열기와 4개 분석 카드 표시.
2. 초기 입력의 유효성.
3. m/s → m/min 값 변환.
4. 단위 변경 전후 계산 결과 유지.
5. 명시적 이상 조건 선택 후 보정 처리량 표시.
6. 3축 × 속도/가속도 6개 그래프.
7. 운동 재생 시각 증가.
8. 위치/속도 그래프 모드 전환.
9. WebGL 렌더러 생성.
10. 시뮬레이션 종료 및 재고 보존.
11. 측정 처리량 표시.
12. 완료 작업 CSV 다운로드.
13. 실행 시드가 포함된 Markdown 계산서 다운로드.
14. 잘못된 랙 치수의 계산 차단.
15. 프로젝트 JSON 불러오기 후 설정 복원.
16. 3개 모드 × 5회 = 15회 반복 실험 종료.
17. 실험 취소 후 재실행 버튼 복원.
18. 모바일 폭 390px에서 문서 가로 넘침 없음.
19. JavaScript page error 0건.
20. HTTP/HTTPS 런타임 요청 0건.

화면 캡처를 직접 확인해 계산 대시보드와 3축 선도의 배치·가독성을 검토했습니다. 3D 정적 프레임 묶음 처리 중 재고 InstancedMesh가 포함되는 표시 결함을 수정했고, 별도 `scene-check.js`에서 실제 재고 메시의 연결, 300개 초기 재고 변환, 전체 600셀, draw call 수, 재생과 시점 전환을 확인합니다. 상세 수치는 `scene-results.json`에 기록합니다.

## 예시 계산

기본 입력(30 Bay × 10 Level × 2면, L=60m, H=20m, 주행 3m/s, 승강 1m/s, 포크 스트로크 1.2m)의 결과:

| 항목 | 결과 |
| --- | ---: |
| SC 평균 | 49.1374311239 s |
| DC 평균 | 75.9368751008 s |
| 포크 이재 1회 | 6.5 s |
| 1대 이론 총 취급량 (분석 DC 100%) | 94.8155950642 PLT/h |
| 전체 피크 요구량 | 84 PLT/h |
| 기본 시드의 준비운전 10분 + 측정 2시간 총 취급량 | 84 PLT/h |

기본 보정계수는 미선택입니다. 예시값은 실제 설비 성능 보증이나 FEM 검증 골든값이 아닙니다. 표본 DC 결과는 고정 시드 9851, 30,000쌍의 셀 평균입니다. 실제 DES의 DC 비율은 도착과 재고 제약으로 분석 비율과 다릅니다.

## 검증 환경과 한계

- Node.js 24.18.1. 브라우저 UI 확인은 독립 임시 디렉터리의 Playwright 1.55.1과 Edge의 소프트웨어 WebGL에서 수행.
- 연결된 Browser 세션이 없어서 로컬 브라우저 자동 검증으로 대체했습니다.
- Drive 가상 파일시스템에 큰 PNG를 직접 쓰는 중 UNKNOWN/write 오류가 발생해, 캡처는 로컬 임시 폴더에서 완성 후 산출물 폴더에 복사했습니다.
- 기존 비교 데이터의 출처와 SHA-256, 조건은 `tests/legacy-golden.json`에 있습니다. 기존 HTML 골든이며 기존 Python/FEM 원문/실측 골든과 구분합니다.
- 실제 장비 FAT/SAT 대조, FEM 대표점 규격 검증, creep/jerk, 다중 깊이, 다중 스테이션, 공유레일 충돌, 고장, Worker, 최적화기는 이번 합격 범위에 포함하지 않습니다.

### 단별 랙 이재 높이

- Y(k) = 1단 높이 + (k−1) × 단간격. 바닥 기준, 모든 STC 공통.
- 적용 1단 높이: 0.6 m / 단간격: 2.4 m / 최상단: 7.8 m.
- 빈 단간격은 H/단수, 빈 1단 높이는 단간격/2입니다. 전체 셀 평균과 실제 시뮬레이션에 적용하며 FEM 이론 대표점은 H 기준으로 유지합니다.

## 4. 제약 검토

- Single Deep / Single Fork, 균등 셀 배치, STC별 IN/OUT XYZ, 통로당 1대.
- 독립 통로 확장은 균등 부하 배분·공통 상하류 병목 없음의 조건부 분석입니다.
- 목표 부하율: 0.8. 보정계수 미선택으로 설계 판정 대기.
- 입력 A·Ft·Ew 중 1.0인 계수는 해당 손실을 제외하는 이상 조건입니다.
- SC-stay의 분석값은 SC-return 참고값이며 동작별 결과는 DES에서 확인합니다.

## 6. 적용 모델과 검증 범위

- 사용자 개발계획서 v1.2의 비대칭 가감속 정지-정지 운동식과 SC/DC 집계 규칙을 사용합니다.
- FEM 선택 시 FEM 9.851 (06.2003) §4.1~4.6 대표점과 입력 운동·이재·지연 모델을 결합합니다. 현장 시험 및 규격 적합성 판정은 별도입니다.
- 실제 장비 실측·기존 Python 골든 자료와의 현장 검증은 미완료입니다.
- creep, jerk 제한 S-curve, 고장, 다중 깊이, Twin Fork, 공유레일 충돌은 포함하지 않습니다.

## STC별 포트와 FEM 적용

- 좌표: X=주행, Y=승강, Z=포크(각 통로 중심 기준). |Z|가 포트 이재 편도거리입니다.

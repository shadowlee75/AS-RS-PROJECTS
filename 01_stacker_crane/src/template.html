01 랙 & 스테이션 ⌄

번지(Bay) × 단(Level) × 보관면 × 깊이(1 또는 2)를 STC마다 동일하게 생성합니다. X=주행, Y=승강, Z=포크 방향(통로 중심 기준, A면 − / B면 +).

단별 이재 높이 = 1단 높이 + (단 번호−1) × 단간격. 빈 단간격은 랙 높이÷단수, 빈 1단 높이는 단간격÷2를 사용합니다. 최상단 이재 높이는 랙 높이 이하여야 합니다.

기본 IN / OUT 포트 좌표

빈 OUT X·Y는 IN을 따릅니다. 빈 Z는 −스트로크입니다. |Z|는 선택한 보관 방식의 최대 스트로크 이내이며, 실제 포크 이동거리는 |Z|입니다. 더블딥에서도 빈 포트 Z는 앞열 스트로크를 따릅니다.

랙 왼쪽 끝 X=0, 오른쪽 끝 X=랙 길이입니다. 왼쪽 외부는 음수(예: −3), 오른쪽 외부는 랙 길이보다 큰 X를 입력하세요. Y도 기준면 아래 음수와 랙 높이 초과를 허용합니다. 기본·STC별 좌표 모두 동일하게 적용됩니다.

STC별 CASE를 선택하면 해당 참조 배치를 사용합니다. 좌표를 입력하면 참조값보다 우선합니다. CASE가 기본이면 기존 기본 좌표를 따릅니다.

FEM 대표점 계산 기준 ⌄

기본 모드는 P1·P2를 가까운 실제 화물 중심으로 옮겨 계산합니다. 외부 포트는 입력한 위치를 유지합니다. CASE 포트 배치 적용 버튼은 입력 포트를 참조 배치로 바꿉니다.

배치 적용은 기본 좌표와 개별 기본 포트의 X·Y를 CASE 조건으로 설정합니다. 복합 포트 조합 표는 별도로 유지됩니다. 높이 또는 X는 기본 IN 값(0이면 H/2 또는 L/2)을 사용합니다. 이후 각 좌표를 직접 조정할 수 있습니다.

MODEL & ASSUMPTIONS

계산 기준과 1차 구현 범위

1단 높이와 단간격

바닥 기준의 1단 랙 이재 높이와 일정한 단간격을 입력합니다. k단의 Y = 1단 높이 + (k−1) × 단간격입니다. 단간격이 비어 있으면 H/단수, 1단 높이가 비어 있으면 단간격/2를 사용하여 이전 프로젝트의 셀 위치를 유지합니다. 전체 셀 평균, 실제 셀 운동 경로, 3D 랙과 재고, 모든 STC의 시뮬레이션에 동일한 높이를 사용합니다. CASE 기준 셀 계산의 P1·P2는 위 좌표의 화물 중심입니다. 비교용 이론 좌표는 H 기준으로 산출합니다.

한 번의 움직임을 같은 기준으로

속도 입력·표시는 기본 m/min이며, 계산과 프로젝트 JSON은 m, m/s, m/s², s를 사용합니다. 각 축은 정지 출발·정지 도착의 삼각형 또는 사다리꼴 속도 프로파일을 사용합니다. 가속도와 감속도를 독립 입력하며, 주행·승강은 동시에 출발합니다.

scrit = v² / 2 × (1/a + 1/d)
s < scrit: vp = √[2s / (1/a + 1/d)], t = vp × (1/a + 1/d)
s ≥ scrit: t = s/v + v/2 × (1/a + 1/d)
이동시간 = max(tx, ty) + 정위치 시간 (실제 이동할 때 1회)

사이클과 총 취급량

SC 입고는 I/O 상차 → 랙 이동 → 랙 하차 → I/O 공차 복귀입니다. SC 출고는 I/O → 랙 공차 이동 → 랙 상차 → I/O 하차입니다. DC는 IN 상차 → 입고 셀 하차 → 출고 셀 상차 → OUT 하차 → IN 공차 복귀입니다. 상차는 포크 OUT → 캐리지 UP → 포크 IN, 하차는 OUT → 캐리지 DOWN → IN이며 이재 승하강량 기본값은 110 mm입니다. 포크 완전 신장 상태에서 승하강하고 안착 대기 후 인입합니다. 제어 지연은 사이클당 한 번입니다.

랙과 포트의 Y, P1·P2는 화물이 놓인 중심 위치입니다. 적재 이동은 그보다 이재 승하강량만큼 높은 위치에서 진행하며 하차 시 원래 중심으로 내려놓습니다. 재고와 작업 완료 수량은 각 포크 IN 완료 시 집계합니다.

p = DC 사이클 수 / 전체 사이클 수
Q = 3600(1+p) / [(1−p)Tsc + pTdc]
Qavailable = Q × 운전효율(%) / 100
운전효율 미입력 시: Qavailable = Q × A × Fₜ × E𝑤
필요 독립 통로 = ceil(피크 요구량 / (Qavailable × 목표 부하율))

DC 분석은 입·출고 구성으로 가능한 최대 p = min(입고, 출고) / max(입고, 출고)를 사용합니다. 전체 셀 평균은 모든 셀의 SC를 열거하고 DC의 서로 다른 셀 간 이동은 전수 또는 고정 시드 30,000쌍을 계산합니다. FEM 모드는 CASE 대표 경로의 평균입니다. 입출고 시간이 다른 경우 DC 페어링 후 남는 SC 작업의 입출고 비중으로 가중합니다. 재고·도착 제약으로 실제 DC 비율은 낮아질 수 있습니다. SC-stay 분석 카드는 SC-return 참고값을 표시하며 실제 동작은 시뮬레이션에서 계산합니다.

시뮬레이션의 집계 경계

입고는 랙 하차 완료, 출고 취급은 I/O 하차 완료로 집계합니다. 출하량은 출고 버퍼에서 외부로 반출된 수량입니다. 준비운전 중 동작과 재고는 이어지지만 통계 시간은 제외합니다. 측정 처리량은 측정구간 안에 완료된 작업 수 / 측정시간이며, 준비운전에서 넘어온 작업도 완료량에 포함됩니다.

평균·P95 대기는 측정구간에 서비스를 시작한 작업의 도착→배차 시간입니다. 종료 시 아직 대기 중인 작업은 별도의 대기 건수와 최장 경과시간으로 표시합니다. 버퍼 초과 시간, 출고 차단, 재고 부족 대기를 분리합니다. 출고 픽업 후 I/O에 도착하지 않은 화물은 크레인 위 출고 재고로 보존식에 포함합니다.

FEM CASE 1~6

FEM 9.851 (06.2003) §4.1~4.6의 포트 배치와 대표점 좌표를 사용합니다. CASE 2의 SC 출고 대표점은 OUT 기준으로 X를 대칭 이동하며, DC는 기본 경로와 대칭 경로의 평균입니다. CASE 3·4는 포트가 H/2·L/2를 넘을 때 대표점 식이 바뀝니다. CASE 5·6은 높이의 1/6을 대표점에 더합니다.

α=(H/L)×(vx/vy), 권고 범위 0.5<α<2를 벗어나면 주의 문구를 표시합니다. 기본 모드는 가까운 실제 화물 중심으로 옮겨 설계 계산합니다. 이론 좌표 비교 모드는 CASE 포트 조건을 검사하고 원래 연속 좌표를 사용합니다. 외부 포트 적용은 CASE 참조점에 실제 이동거리를 결합한 설계 확장입니다. 현장 측정과 규격 적합성 판정을 대신하지 않습니다.

지정 SC/DC 비율과 복합 배치

싱글과 듀얼 합계는 100%입니다. 사이클 비율 p의 경우 DC 1회는 화물 2개이며, 화물 기준 DC 비율 f는 p=f/(2−f)로 환산합니다. 분석 p는 입출고 비대칭에 따른 상한 min(IN,OUT)/max(IN,OUT) 이내로 적용합니다. 실제 운전은 재고·도착·버퍼 때문에 지정값과 다를 수 있으며 측정구간의 완료 사이클로 달성 비율을 표시합니다.

복합 조합의 배분율 합계는 STC마다 100%입니다. 조합 전환 평균은 각 조합과 SC 입출고 방향을 독립 선택한다고 가정한 공차시간입니다. 포트 복귀 사이클을 기준으로 하므로 실제 순서 의존성과 SC-stay는 DES를 확인하세요. 복합 배치는 FEM 참조 CASE를 조합한 설계 확장입니다.

포트·다중 STC 및 집계

X=주행, Y=승강, Z=포크 신장 방향입니다. Z는 각 통로 중심의 로컬 좌표이며, 통로 이동축을 뜻하지 않습니다. IN 상차·OUT 하차의 포크 거리는 각 포트의 |Z|, 랙 이재 거리는 선택한 앞열·뒷열 스트로크입니다. DC에는 OUT→IN 공차 복귀가 포함됩니다. 기본 좌표와 STC별 개별 좌표를 저장할 수 있습니다.

입력한 STC 수만큼 독립 통로와 실제 이벤트 엔진을 생성합니다. 전체 수요를 균등 배분하고 각 통로는 서로 다른 재고·도착 시드를 사용합니다. 화면 합계는 실제 관측량의 합, 가동률은 전체 대수의 시간 평균, P95 대기는 모든 배차 표본을 합쳐 계산합니다. 포트가 다른 설비의 필요 대수는 현재 입력 중 가장 낮은 능력을 기준으로 보수적으로 산정합니다.

싱글딥·더블딥

화물 보관 깊이는 SC/DC 운전 모드와 별개입니다. 더블딥은 각 번지·단·면에 D1(앞열), D2(뒷열)를 생성합니다. 앞열 스트로크는 통로 중심부터 앞열 중심, 뒷열 스트로크는 통로 중심부터 뒷열 중심까지의 총 거리입니다. 뒷열을 비우면 앞열의 2배를 설계 가정으로 사용하므로 실제 사양을 확인하여 입력하세요.

분석은 앞열·뒷열 50:50 이재시간 평균이며 FEM 결합은 설계 확장입니다. 시뮬레이션은 뒷열 우선 입고, 앞열이 비어 있을 때만 뒷열 접근, 접근 가능한 재고 내 FIFO를 적용합니다. 같은 번지·단·면의 앞열·뒷열은 하나의 DC로 묶지 않습니다. SKU 지정 출고와 재배치 작업은 포함하지 않습니다.

지원 범위

균등 셀 배치, Single / Double Deep, Single Fork, 통로당 STC 1대, STC별 CASE 1~6 및 최대 6개 I/O 조합을 지원합니다. 조합별 수요 배분, 동일 조합 DC 페어링, 좌표가 같은 동종 포트의 버퍼 공유를 적용합니다. IN과 OUT은 같은 좌표여도 서로 다른 대기 버퍼로 취급합니다. 모든 STC를 한 장면에서 재생하고 번지·단·면을 동일한 셀 데이터로 표시합니다. 공용 상하류 병목, 공유 레일 충돌, 통로 간 이동, 다중 깊이 재배치, jerk 제한, creep, 고장 이벤트는 포함하지 않습니다.

평균 사이클타임과 달성 가능한 처리량은 함께 검토해야 합니다. 물동량만으로 대기시간이나 설비 성능을 확정할 수 없습니다.

복합 입·출고 포트 구성

한 STC가 여러 입·출고 조합을 함께 처리합니다. 행이 없는 STC는 기본 포트를 사용하고, 행이 있는 STC는 아래 조합만 사용합니다.

STC별 배분율 합계 100% · 입고·출고 각각에 같은 배분율 적용 · 최대 6개 조합. 추가/삭제 시 해당 STC 배분율을 자동 환산합니다. 빈 좌표는 CASE 참조 배치(H/2, L/2)를 사용하며 Z는 기본 포크 좌표를 따릅니다.

동일 좌표의 IN끼리, OUT끼리는 버퍼를 공유합니다. IN/OUT 버퍼 용량과 반출 간격은 각 물리 포트에 적용합니다. 편집을 마친 후 계산 및 설정 적용을 눌러 반영하세요.

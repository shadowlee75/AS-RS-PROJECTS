# FEM CASE 적용 및 좌표 기준 · STC Studio 0.2.4

기준 자료: 사용자 폴더의 **FEM 9.851 (06.2003), Performance Data of S/R Machines Cycle Times** §4.1~4.6. 계산식은 로컬 `FEM-9_851_Englisch (Performance Data of SR Machines Cycle Times) - Text.md` 및 `FEM 9.851 Text 정리 (230417).md`와 대조했습니다. 규정 대표점과 입력한 가감속·포크·정위치·제어 지연 모델을 결합한 설계 계산입니다.

## 화면에서 적용

1. **대표점 계산 기준 → FEM CASE 기준 · 대표 셀 계산**을 선택합니다.
2. CASE 1~6 중 설비 배치에 맞는 항목을 선택합니다.
3. 기본 **P1·P2 적용 위치 → 실제 화물 중심**을 사용합니다. CASE 참조점과 가까운 실제 셀의 중심 XYZ를 계산에 사용합니다.
4. 기본 좌표 또는 STC별 표에 실제 포트를 입력합니다. 음수 X/Y, 랙 길이·높이 밖의 좌표를 허용합니다. **CASE 포트 배치 적용** 버튼은 참조 배치로 좌표를 덮어쓰므로, 외부 포트를 입력했다면 누르지 않고 계산을 적용합니다.
5. **계산 및 설정 적용**을 누릅니다. 적용 중심 XYZ·셀 주소·비교용 이론 XYZ, STC별 SC/DC 및 OUT→IN 복귀시간을 확인합니다.
6. **운동 그래프 → 경로: CASE P1·P2 적용점**에서 같은 경로를 확인합니다. CASE 2는 기본/대칭 경로를 각각 선택할 수 있습니다.
7. 모든 셀의 평균은 **전체 셀 평균 · 자유 포트 좌표**, 기존 연속 좌표의 비교는 **FEM 이론 좌표 · 비교**를 선택합니다. 이론 좌표 모드는 아래 포트 조건을 엄격히 검사합니다.

## 실제 화물 중심과 이론 좌표의 구분

기본 모드는 이론 XYZ에서 가장 가까운 실제 셀을 결정하고, 이후 모든 계산과 그림에는 **그 화물 중심의 XYZ**를 사용합니다. 셀 X=(번지−0.5)×L/Bay수, Y=1단 이재 높이+(단−1)×단간격, Z=해당 보관면의 부호×포크 스트로크입니다. XYZ 직선거리로 선정하고 등거리이면 작은 셀 ID를 우선합니다. 두 대표점이 같은 셀로 겹치면 P2는 P1을 제외한 가장 가까운 셀을 사용합니다. 단일 셀은 DC가 없습니다.

실제 포트가 아래 CASE 배치 조건과 다르면, 참조 포트를 CASE 배치로 구성해 대표 셀을 선정한 다음 **실제 입력 포트**로 SC/DC 경로를 계산합니다. 참조 높이와 X는 랙 범위 안으로 제한하고, CASE 포트 예시의 0 높이/위치 대체 규칙을 사용합니다. 두 실제 포트가 랙 오른쪽에 있으면 참조 배치를 좌우 반전합니다. 실제 포트는 덮어쓰지 않으며 계산서에 셀 선정 참조 포트와 적용 포트를 모두 기록합니다. 이는 원 규정 배치 그대로의 이론 계산과 구분하는 **설계 확장**입니다.

CASE 참조 포트 생성: CASE 3/5/6은 양수 IN Y, 이어서 OUT Y, 없으면 H/2를 높이 h로 사용합니다. CASE 4는 양수 IN X, 없으면 L/2를 사용합니다. 이 규칙은 참조점 선택용이며 실제 포트의 높이 차를 자동으로 다른 좌표계로 변환한 규정식이 아닙니다.

CASE 선택은 분석의 대표점 계산에 적용됩니다. 운영 시뮬레이션은 입고 가능한 빈 셀·출고 가능한 재고 셀을 실제로 선택하며, 대표점만 반복 방문하는 애니메이션이 아닙니다.

## 포트 조건과 대표점

E=IN, A=OUT, L=최대 주행 경로, H=최대 승강 경로. 아래 표는 XY 좌표입니다.

| CASE | 포트 배치 | P1 | P2 |
| --- | --- | --- | --- |
| 1 | E=A=(0,0) | (L/5, 2H/3) | (2L/3, H/5) |
| 2 | E=(0,0), A=(L,0) | (L/5, 2H/3) | (2L/3, H/5) |
| 3 · h≤H/2 | E=A=(0,h), 0<h≤H/2 | (L/5, 2H/3+h/3) | (2L/3, H/5+h/3) |
| 3 · h>H/2 | E=A=(0,h), H/2<h≤H | (L/5, h/3) | (2L/3, 7H/15+h/3) |
| 4 · x≤L/2 | E=A=(x,0), 0<x≤L/2 | (L/5+x/3, 2H/3) | (2L/3+x/3, H/5) |
| 4 · x>L/2 | E=A=(x,0), L/2<x≤L | (7L/15+x/3, 2H/3) | (x/3, H/5) |
| 5 | E=(0,0), A=(0,h), 0<h≤H | (L/5, 2H/3+h/6) | (2L/3, H/5+h/6) |
| 6 | E=(0,h), A=(0,0), 0<h≤H | (L/5, 2H/3+h/6) | (2L/3, H/5+h/6) |

CASE 2의 OUT 측 대표점은 A에서 측정한 상대 X를 전역 X로 변환하여 **P1′=(4L/5,2H/3), P2′=(L/3,H/5)**로 계산합니다.

- SC 입고: E→P1→E, E→P2→E 완전 사이클의 평균.
- SC 출고: A→P1→A, A→P2→A 평균. CASE 2는 P1′, P2′ 사용.
- DC: E→P1→P2→A→E.
- CASE 2 DC: 위 경로와 E→P1′→P2′→A→E의 평균.

입고 적재 이동과 출고 적재 이동에는 적재 저감이 적용되며 나머지 이동은 공차입니다. 포크는 SC 2회/DC 4회, 정위치는 실제 XY 이동이 있는 구간마다 한 번, 제어 지연은 사이클당 한 번입니다. 규정의 t01/t02에 해당하는 지연을 이 항목에서 계산하므로 별도의 t01/t02를 중복 가산하지 않습니다.

v0.2.4는 사용자 지정 이재 순서를 적용합니다. **상차 OUT → 캐리지 UP 110 mm → IN**, **하차 OUT → 캐리지 DOWN 110 mm → IN**이며, 이는 해당 장비의 입력 사양으로 FEM 규정 자체의 고정 승하강량을 뜻하지 않습니다. 승하강 중 포크는 완전 신장 상태로 정지하고 승하강 완료 후 입력한 안착 대기를 거쳐 인입합니다. 이재 1회는 포크 편도 운동 2회 + 캐리지 승하강 운동 1회 + 안착 대기입니다.

P1·P2와 랙·포트 Y는 화물이 놓인 중심 좌표를 유지합니다. 상차 후 적재 이동은 입력 중심보다 이재 승하강량만큼 높은 Y에서 진행하고, 하차하면 입력 중심으로 내려갑니다. 캐리지 이재는 승강 Y 속도·가감속에 적재 비율을 적용하여 계산합니다. 기존 승하강·안착 시간에 운동시간이 포함되어 있었다면 안착 대기만 입력하여 중복을 피합니다. 새 승하강량 입력은 mm, JSON 저장은 m이며 기본값은 110 mm입니다.

`α=(H/L)×(vx/vy)`가 규정의 권고 범위 `0.5<α<2` 밖이면 화면과 계산서에 주의를 표시합니다. 위 표는 비교용 이론 좌표이며 기본 설계 계산의 적용점은 실제 화물 중심입니다. 실제 시험 반복·실측 허용오차 판정·규격 인증 기능은 포함하지 않습니다.

## XYZ와 실제 랙 셀

- X: 랙 왼쪽 끝 0, 오른쪽 끝 L. 포트는 −500~500 m로 외부 좌표 허용.
- Y: 기준면 0. 포트는 −100~100 m로 아래쪽 음수 및 랙 높이 밖의 좌표 허용.
- Z: 해당 STC 통로 중심에서 포크가 신장하는 방향과 거리. A면 음수, B면 양수.
- IN/OUT의 이재 편도거리는 각 포트의 |Z|. 입력 포크 스트로크 이하이어야 합니다.
- 랙 이재의 편도거리는 스트로크. 랙 셀 Z는 ±스트로크입니다.
- 이 프로그램의 Z는 FEM §2.3.3에 등장하는 통로 간 이송축이 아닙니다. 크레인이 통로 사이를 이동하는 장비는 모델링하지 않습니다.
- 셀 좌표: X=(번지−0.5)L/Bay수, Y=1단 랙 이재 높이+(단−1)×단간격. 1단 높이는 바닥 기준 Y(m)입니다.
- 빈 단간격은 H/Level수, 빈 1단 높이는 단간격/2입니다. 모두 자동이면 이전 Y=(단−0.5)H/Level수와 같습니다. 최상단 이재 높이는 H 이하여야 합니다.
- 입력한 단별 높이는 전체 셀 평균 계산, 실제 셀 운동 그래프, 2D/3D 랙, 모든 STC의 시뮬레이션과 기본 P1·P2 선정에 적용합니다. 셀 중심이 바뀌면 대표 셀과 계산 결과도 바뀔 수 있습니다. 이론 좌표 비교 모드에서만 H·포트·운동 사양이 같으면 이론 처리량을 유지합니다.
- 주소: `STC03-B-012-06` = 3호기 B면 12번지 6단.
- 각 STC는 동일한 랙 규격을 사용합니다. 시각화에서 통로 중심을 분리해 배치하되 포트 입력은 각 통로의 로컬 좌표입니다.

속도 입력과 그래프·실시간 표시·계산서는 기본 **m/min**이며, 주행/승강/포크 예시는 180/60/36 m/min입니다. 가감속은 m/s², 내부 계산과 프로젝트 JSON의 속도는 m/s입니다. α 계산은 두 속도에 동일한 단위를 사용하므로 표시 단위에 따라 값이 바뀌지 않습니다.

## 처리량과 운영 모형

입·출고 수요를 I/O, 전체 사이클 중 DC 비율을 p라 하면, 가능한 DC 수요는 D=min(I,O), 잔여 SC는 I−D와 O−D입니다(DC 모드). 이 잔여 비중으로 SC 입고/출고 시간을 가중합니다. 시간당 처리능력은 총 취급량 I+O와 이에 필요한 총 사이클 시간을 사용합니다. 입고/출고 시간이 다른 설비에 같은 SC 평균을 일률 적용하지 않습니다.

STC 수만큼 독립 이벤트 엔진을 실행하고 전체 수요를 균등 배분합니다. 통로 i(0부터)의 시드는 `(기본시드 + 104729×i) mod 2³²`, 반복 r에서는 기본시드에 r을 더합니다. 각 STC의 예약·재고·큐·좌표·포크를 따로 계산합니다.

전체 처리량은 관측 완료량의 합, 가동률은 대수×측정시간 기준 시간 평균, P95는 모든 배차 대기 표본을 합친 분위수입니다. 상태·차단·재고 부족 시간은 STC 시간의 합으로 표기합니다. 포트 배치가 다르면 전체 분석 능력도 STC별 능력의 합입니다. 필요 대수는 입력 STC 중 가장 낮은 보정능력을 기준으로 보수적으로 산정하며 공용 상하류 병목은 별도 검토 대상입니다.

# 직선 RGV 물동량 계산 프로그램

버전 0.2.0 · 2026-09-11

[직선RGV_실행.html](../직선RGV_실행.html)을 Edge 또는 Chrome으로 열면 실행됩니다. 서버나 별도 설치 없이 파일 하나로 계산·시뮬레이션·보고서 작성이 가능합니다. 개발과 브라우저 검증은 Windows의 Edge에서 수행했습니다.

## 기능

| 기능 | 구현 범위 |
|---|---|
| 차량 구성 | 단일 구간 1대, 물리적 독립 구간당 1대, Tandem 직렬 인계 구간당 1대 |
| 설비 입력 | 스테이션, 담당 구간, 대기점, 거리행렬, 상·하차 시간, 출고·인계 버퍼 |
| 주행 계산 | 공차·적재 별도 사양, 비대칭 가감속, 연속 경계속도, 제한속도, 중간 정지, 도착 저속 접근 |
| 수요 | 양방향 OD, 피크·시간대 배율, 배치 적재, 작업이력 CSV |
| 분석 | OD 사이클, 병목 처리능력, 보정능력, 목표 부하율 부족량, 작업부하 환산 대수 |
| 시뮬레이션 | FIFO/가까운 작업, 대기점 복귀/위치 대기, 유한 버퍼 차단, 실제 화물 보존, 준비운전 제외 통계 |
| 화면 | 전체 차량 3D 재생, 회전·확대·이동, 정면·평면·입체 시점, 선택 차량 추적, 상·하차 화물 이동, 시간 탐색, 운동 선도·운영 통계 |
| 실험 | 4가지 배차·대기 조합, 정책당 5/10/20/30회, 공통 수요 시드, 평균 처리량 95% CI |
| 저장 | 입력·작업이력 JSON, 완료작업 CSV, 실험 JSON, 계산서 Markdown, A4 보고서 인쇄/PDF 저장 |

같은 레일에서 여러 차량이 교행·추월하는 구성은 지원하지 않습니다. 분석에 표시되는 환산 대수는 작업부하 참고값이며 실제 같은 레일에 투입 가능한 대수가 아닙니다. Tandem 처리능력도 구간별 처리량을 합산하지 않습니다.

## 빠른 사용

1. 실행 HTML을 열고 `설정 예시`를 선택하여 `예시 적용`을 누릅니다.
2. 왼쪽 사양과 `설비·스테이션`, `OD·시간대` 탭의 입력을 설비 조건에 맞게 바꿉니다.
3. `계산 및 설정 적용`을 누른 후 전체 능력·병목·목표부하 부족량을 확인합니다.
4. `3D 시뮬레이션 → 종료까지 계산`으로 버퍼 차단과 관측 처리량을 확인합니다.
5. `프로젝트 저장`으로 입력을 보관하고 필요에 따라 CSV·MD·PDF 보고서를 내보냅니다.

보정계수와 근거를 선택하지 않으면 보정능력과 환산 대수는 보류됩니다. `이상 조건 1.0`은 비교 기준이며 실측 계수라는 뜻이 아닙니다. 입력 변경·불러오기·재적용은 이전 실행 결과를 초기화하므로 먼저 내보내세요.

3D는 스태커크레인과 동일한 Three.js r128 및 OrbitControls를 실행 HTML에 포함합니다. 드래그 회전·휠 확대·우클릭 이동을 지원합니다. 차량을 클릭하거나 선택 목록에서 고르고 `선택 차량 확대`를 누릅니다. `차량 추적`을 켜면 카메라가 주행을 따라갑니다. 전체·정면·평면 보기로 바꾸면 추적을 해제합니다.

차량 X는 실제 엔진 좌표이며, 차체 치수·이재 높이·구간 간 Z 간격은 설명용 도식입니다. Tandem도 구간을 나란한 행으로 분리하여 인계를 보여줍니다. 버퍼는 최대 8개 화물을 그리고 실제 수량·예약은 이름표로 표시합니다. 상차 중 옮겨지는 화물은 버퍼와 차량에 중복 표시하지 않습니다. WebGL을 사용할 수 없으면 2D로 대체하며 설정 재적용 시 3D를 다시 시도합니다.

## 모델의 경계

- 수요 생성 모드는 같은 OD의 완전 배치만 생성합니다. CSV 한 행은 한 작업이며 수량은 1회 최대 적재량 이하입니다. 서로 다른 OD의 화물 합적·분할 적재는 모델링하지 않습니다.
- 출발 작업 대기는 용량 제한 없는 외부 대기열입니다. 스테이션 버퍼는 **최종 목적지의 출고 버퍼**이고 인계 버퍼는 방향마다 별도입니다.
- 스테이션마다 상·하차 공용 이재부 1개가 있습니다. 인계 장치의 상·하차는 입력한 시간으로 표현하며 별도의 공용 컨베이어·PLC 자원은 없습니다.
- 배치 화물은 `수량 × 외부 반출 간격` 후 배치 전체가 반출됩니다. 한 배치 안에서 화물별 반출 시각을 나누지 않습니다.
- 위치 대기의 정적 분석은 이전 도착지와 다음 출발지의 독립 혼합을 가정합니다. 실제 배차 순서·차단 영향은 시뮬레이션에서 확인합니다.
- 시간대별 수요는 각 시간대 시작에서 도착간격을 새로 생성합니다. 시간대 공백에는 도착이 없습니다. 준비운전의 화물과 상태는 측정구간으로 이어집니다.
- 보정계수는 정적 차량 능력에만 한 번 적용합니다. 시뮬레이션은 고장 없는 운동·운영 모델이며 보정계수를 다시 곱하지 않습니다.
- jerk는 유효 가감속 저감 또는 시간 가산 근사입니다. 정밀 S-curve, 차량 길이·안전거리, 실제 제어기, 설비 고장, SKU 호환성, 자동 최적화는 구현 범위에 포함하지 않습니다.

## 개발

실행에는 Node.js가 필요하지 않습니다. 수정·빌드·핵심 검증에는 Node.js 18 이상을 사용합니다. 외부 npm 패키지 없이 빌드와 핵심 검증을 수행합니다.

```powershell
node --test tests/core.test.js
node scripts/build.js
node scripts/shipcheck.js
node scripts/examples.js
```

배포 HTML은 소스를 수정한 뒤 다시 빌드해야 반영됩니다. `shipcheck`는 배포 HTML에서 실제 인라인 코드를 추출하여 소스 SHA-256 일치와 핵심 검증을 다시 확인합니다.

브라우저 검증은 Edge와 Playwright가 필요합니다. 기존 Playwright 모듈 경로를 `RGV_PLAYWRIGHT_PATH` 환경변수로 지정하거나 개발 환경에 Playwright를 설치하고 실행합니다.

```powershell
npm install --no-save playwright
node scripts/browser-check.js
node scripts/scene-check.js
```

| 경로 | 역할 |
|---|---|
| `src/motion.js` | 이동시간과 연속 운동 프로파일 |
| `src/model.js` | 입력 검증, OD 경로, 정적 부하·능력, 프로젝트 형식 |
| `src/engine.js` | 시드 기반 이벤트 시뮬레이션, 버퍼·화물 상태, 통계 |
| `src/view.js` | SVG 레이아웃·운동 그래프와 결과 표시 |
| `src/scene.js` | 엔진 상태를 읽는 3D 장면, 카메라·차량 선택·이재 애니메이션·2D 대체 표시 |
| `src/report.js` | CSV 입출력, 계산서, A4 보고서 |
| `src/app.js` | 입력 편집, 재생, 내보내기, 반복 실험 |
| `src/template.html`, `src/style.css` | 화면 구조와 스타일 |
| `tests/invariants.js` | 소스·배포 파일에 공통 적용하는 검증 |
| `tests/scene-invariants.js` | 3D 좌표·화물 소유권·엔진 결과 불변 검증 |
| `vendor/` | Three.js r128, OrbitControls, MIT 라이선스와 SHA-256 출처 기록 |
| `qa/` | 배포 검증 결과, 브라우저 결과와 화면 |

이번 버전은 개발계획의 직선 RGV 범위에 맞춰 새로 구현한 초기 버전입니다. 계획서에 언급된 기존 직선 RGV 코드와 16개 검증 원본은 작업공간에서 확인하지 못했으므로, 해당 기존 검증을 재현했다고 주장하지 않습니다. 이번 검증과 현장 실측 검증은 구분합니다.


## 3D 화면 이동 · 2026-09-16

3D 화면 안에서 **마우스 휠 버튼(가운데 버튼)을 누른 채 드래그**하면 화면이 상하좌우로 이동합니다. 휠을 굴리면 확대·축소하고, 좌클릭 드래그는 회전, 우클릭 드래그는 이동입니다. 장비 선택은 좌클릭으로 합니다. 변경된 실행 HTML을 새로 열면 적용됩니다.

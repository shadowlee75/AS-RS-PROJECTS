# 직선 RGV v0.2.0 · 3D 시뮬레이션 검증

검증일: 2026-09-11 · Windows / Node.js / Microsoft Edge 138.0.3351.95

대상: [직선RGV_실행.html](../../직선RGV_실행.html)

## 변경 내용

스태커크레인과 동일한 Three.js r128·OrbitControls를 포함하여 시뮬레이션을 3D로 변경했습니다. 레일·차량·스테이션·인계 버퍼, 배치 화물, 상·하차 이동을 표시하며 마우스 회전·확대·이동, 정면·평면·입체 보기, 차량 클릭 선택·확대·추적을 제공합니다.

3D는 엔진의 좌표와 상태를 읽습니다. 화물 이재 표현은 이재시간의 경과율을 사용하며 계산 엔진을 변경하지 않습니다. 차체 크기와 Y/Z 배치는 설명용입니다. 버퍼의 표시 화물은 최대 8개이고 실제 점유·예약은 숫자로 표시합니다.

## 3D 핵심 확인

- 실제 X 좌표와 독립 구간, 스테이션·방향별 인계 버퍼 위치 매핑.
- 모든 이동 시각에서 렌더링 차량 위치·적재 상태와 엔진 일치.
- 상차 중간 시각의 화물 이동 위치, Tandem 상차 화물 중복 표시 방지.
- 차단 차량의 화물 유지, 실제 버퍼 점유와 예약의 일치.
- 장면 프레임을 계산하며 실행해도 같은 시드의 완료 로그·화물 보존이 동일.
- 스테이션과 인계 버퍼 ID가 같을 때에도 재고 구분.

## 브라우저 3D 확인

파일 URL에서 오프라인 실행했습니다. 3D 전용 검사는 Edge의 소프트웨어 WebGL 렌더링을 사용하여 자동화 환경에서도 실제 WebGL 장면을 확인했습니다.

초기 렌더링, 차량·스테이션 개수, 정적 도형 묶음 처리(기본 장면 draw call 70회 미만), 정면·평면·입체 시점, 이름표 숨김, 일시정지 상태의 드래그 회전·휠 확대, 상차 화물 이동, 엔진과 같은 적재 주행 위치, 차량 추적, 재생, 과거 시각 탐색, Tandem 양방향 버퍼·차단·재고, 차량 선택·확대·직접 클릭, 모바일 크기 변경을 확인했습니다.

WebGL 컨텍스트 손실을 발생시켰을 때 2D 대체 화면과 안내가 나타나고 3D 조작 버튼이 비활성화되는 것을 확인했습니다. 설정 재적용 시 이전 장면을 해제하고 WebGL 장면을 다시 생성했습니다. 배포 파일 하나에 3D 라이브러리와 MIT 라이선스를 포함했습니다.

## 검증 범위

이번 변경은 시각화입니다. 실제 차체 치수·안전거리·상하차 장치의 세부 축 운동을 입력받는 기구 시뮬레이터가 아닙니다. 개별 GPU·브라우저 조합 전체의 검증이나 현장 실측 비교를 수행하지 않았습니다. 설계 계산의 범위와 초기 버전의 검증 경계는 [이전 기록](검증결과_v0.1.0.md)을 참조하세요. `qa`의 공통 JSON·기본 화면 파일은 가장 최근 실행 기록입니다.

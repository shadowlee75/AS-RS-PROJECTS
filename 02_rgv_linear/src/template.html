MODEL & ASSUMPTIONS

계산 근거와 사용 순서

1. 입력 → 적용 → 검토

왼쪽에서 단위·운동 사양·운영 조건을 정하고, 설비·스테이션 탭에서 차량 구간과 포트, OD·시간대 탭에서 수요를 입력하세요. 계산 및 설정 적용 후 결과를 확인하고 프로젝트를 저장합니다. 예시 수치는 설계 가정입니다.

2. 반송 한 건의 경계

배차 제어 → 공차 접근 → 상차 → 적재 이동 → 하차 → 선택적 대기점 복귀입니다. 한 화물은 최종 목적지 하차에서 한 번 완료됩니다. Tandem 중간 인계는 차량별 취급에 포함하지만 전체 완료 물동량에 합산하지 않습니다. 외부 출하량은 출고 버퍼에서 실제 반출된 화물입니다.

3. 운동과 저속구간

scrit = v²/2 × (1/a + 1/d)
s < scrit: t = √(2s × (1/a + 1/d))
s ≥ scrit: t = s/v + v/2 × (1/a + 1/d)

각 이동은 정지 출발·정지 도착입니다. 여러 속도제한 구간은 가능한 경계속도를 전진·후진 계산해 연결합니다. 실제 중간 정지점에서만 속도를 0으로 합니다. jerk 보정은 유효 가감속 또는 이동별 추가 시간 중 하나를 사용하며 정밀 S-curve는 포함하지 않습니다.

4. 이재시간 포함 범위

간편 입력은 정위치·인터록·신호를 포함한 총 상·하차 시간입니다. 상세 입력은 순수 이재시간 + 세 지연의 합입니다. 전환만으로 합계가 바뀌지 않습니다. 각 스테이션은 상·하차 공용 이재부 1개로 모델링합니다. 인계시간은 경계에서 상차·하차 각각 한 번 적용합니다.

5. 분석 능력과 대수 해석

구간 작업부하 [s/h] = Σ(OD 작업 횟수/h × 구간 사이클 s)
차량부하 환산 대수 = ceil(작업부하 / (3600 × A × Fₜ × E𝑤 × 목표 부하율))

대기점 복귀는 실제 복귀거리를 포함합니다. 위치 대기 분석은 이전 도착지와 다음 출발지가 독립이라는 가중 공차 근사입니다. 전체 능력은 차량·스테이션·외부 반출 중 병목 부하로 결정하며 구간별 능력을 합산하지 않습니다. 환산 대수가 2 이상이어도 같은 레일에 차량을 추가할 수 있다는 뜻은 아닙니다. 구간 분할·물리적 독립 증설을 별도 검토하세요.

6. 시뮬레이션 집계

준비운전의 화물·상태는 이어지지만 시간당 통계에서 준비운전 시간은 제외합니다. 측정 중 완료된 화물은 도착시점과 관계없이 완료량에 포함합니다. P95 대기는 측정 중 최초 배차된 작업만 포함하며, 구간별 대기는 인계 후 대기도 포함합니다. 종료는 지정 시각 기준으로 진행·대기 화물이 남을 수 있습니다. 출력 버퍼의 배치 화물은 수량 × 반출간격 후 함께 반출됩니다.

7. 지원 범위

단일 차량·물리적 독립 구간·Tandem 구간당 1대, 양방향 OD, 구간 제한속도, FIFO/가까운 작업, 유한 인계·출고 버퍼를 지원합니다. 같은 레일 다차량 교행·추월·차량 길이·안전거리·실제 PLC·고장 이벤트·SKU 적합성은 포함하지 않습니다. 역방향 인계 버퍼도 별도 공간이 필요하며 양방향 교착 가능성은 DES 경고로 확인합니다.

8. 규격 참고

개발계획서의 표기 기준: FEM 9.860 준용, 규격 적용대상 아님. 운동학을 참고한 설계 모델이며 FEM 규격 인증 기능은 아닙니다. 안전규격 참고는 EN 619:2022 · BSI 안내이며, 해당 설비의 안전 적합성은 별도 검토 대상입니다.

9. 저장·보고서

프로젝트 JSON은 SI 단위의 입력·작업이력을 저장하며 시뮬레이션 진행 상태를 저장하지 않습니다. 입력 변경·불러오기·재적용 전에 필요한 CSV와 보고서를 내보내세요. PDF 보고서 → 보고서 미리보기 → PDF 저장/인쇄에서 A4·PDF로 저장을 선택하고 브라우저 기본 머리글·바닥글을 끕니다.
